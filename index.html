📜 Code Builder 程式碼封包

點擊按鈕一鍵複製完整程式碼，再貼進遊戲內的程式碼建立器中：

# 麥塊伺服器初始化程式碼
def on_chat_setup():
    player.execute('scoreboard objectives add mine_score dummy "挖礦總積分"')
    player.execute('scoreboard objectives setdisplay sidebar mine_score')
    player.say("記分板已啟動！")

player.on_chat("setup", on_chat_setup)
